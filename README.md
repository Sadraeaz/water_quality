# Water Quality Remote Sensing

Notebooks for water quality index retrieval from satellite imagery, using two sensors:

| Sensor | Folder | Indices |
|---|---|---|
| Sentinel-2 L2A | [sentinel2/](./sentinel2) | NDWI, NDCI, Three-band Chl-a, FAI |
| EO-1 Hyperion L1T | [hyperion/](./hyperion) | NDWI, NDCI, Three-band Chl-a, FAI, Phycocyanin, FLH, CDOM |

**Author:** Sadra Emamalizadeh  
**Tools:** Python, openEO, rasterio, xarray, matplotlib
